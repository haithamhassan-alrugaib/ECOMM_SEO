Guide

The short version.

3 Steps to Start

  1. Sign in with your name — for attribution only, not a password.
  2. Goals → set the one metric you're actually trying to move.
  3. Task Priority → add what needs doing with an estimated impact %.

How Ranking Works

Tasks sort by impact % — highest always on top, technical or content. You enter the estimate; the system doesn't calculate it.

Where Everything Lives

  • Dashboard — one-glance goal progress, top tasks, trend, A/B win rate.
  • Data Intake — drop in GA4 / GSC / Matrixify / crawl exports.
  • Analysis — KPI trend, impact-vs-effort chart, tech/content split.
  • Competition — log findings manually, or run live via OpenSEO.
  • Recommendations — the "why" behind a task, with confidence level.
  • A/B Tests — log wins and losses; both count as evidence.
  • Monthly Reports — one click compiles the month's completed work.
  • Integrations — live connection checks + optional Drive backup.
  • Activity Log — who did what, for documentation.
Everything's stored in this browser only, unless you connect optional cloud storage. OpenSEO research and Drive backups are live API calls, not free background actions.
